Tigase JaXMPP v3.3.0 has been released! Please review the change notes below to see what has changed since our last release.

New Features and Fixes:

- Add support for OMEMO (#jaxmpp2-4)
- Add support for [XEP-0305: XMPP Quickstart](http://xmpp.org/extensions/xep-0305.html) (#8245)
- Added SCRAM-SHA512 support (#8459)
- Add support for service discovery extension in CAPS calculation (#8576)
- Added optional support for RSM in disco#items (#pubsub-65)
- Added support for publish-options (#8582)
- Implement Multiple Items in Form Results (#83)
- Improvements to deal with MUC messages sent to bare jid (#8765)
- Fixed an issue with connecting to FCM (#push-23)

New version can be downloaded from [downloads page](https://github.com/tigase/jaxmpp/releases/tag/3.3.0) and [maven repository](https://maven-repo.tigase.org/#browse/tigase)
