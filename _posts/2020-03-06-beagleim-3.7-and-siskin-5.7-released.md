New versions of XMPP clients for Apple's mobile and desktop platforms have been released.

## Common changes

- Improve bookmarks support (proper handling of bookmarks without a name)

## BeagleIM 3.7

Since this version it's possible to also install BeagleIM via [Homebrew](https://brew.sh/) package manager.

First, you need to add our brew tap:
```shell
brew tap tigase/tigase
```

And later install BeagleIM Cask:

```shell
brew cask install beagleim
```

We also decided to start publishing test, beta versions of BeagleIM - you can find it on [BeagleIM's GitHub release page](https://github.com/tigase/beagle-im/releases/) or get it via Homebrew (**IMPORTANT**: Beta versions may contain bugs and cause data loss and should be used only for testing purposes):
```shell
brew cask install beagleim-beta
```

See [our Homebrew tap](https://github.com/tigase/homebrew-tigase) for details

## SiskinIM 5.7

The stable release of SiskinIM 5.7 contains the following changes:

- Fix crash when private chat of MUC is in contacts list
- Improve reliability of establishing XMPP connection

You can download both application from their respective app-stores: [Beagle IM](https://beagle.im/) from [macOS appstore](https://apps.apple.com/us/app/beagleim-by-tigase-inc/id1445349494) and [Siskin IM](https://siskin.im/) from [iOS appstore](https://itunes.apple.com/us/app/tigase-messenger/id1153516838) and star them on GitHub: [Siskin IM on GitHub](https://github.com/tigase/siskin-im) and [Beagle IM on GitHub](https://github.com/tigase/beagle-im)
