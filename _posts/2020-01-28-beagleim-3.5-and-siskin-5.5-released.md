New versions of XMPP clients for Apple's mobile and desktop platforms have been released.

## BeagleIM 3.5

The stable release of BeagleIM 3.5 contains the following changes

- Attachment panel to have quick overview of all exchanged files
- Added support for blocking contacts

![beagle-info]({{ site.url }}{{ site.baseurl }}/assets/posts/beagle-info.png)

- Improved file and image sharing
- Added support for encrypted file transfers
- Added support for link previews

![beagle-chat]({{ site.url }}{{ site.baseurl }}/assets/posts/beagle-chat.png)

- Improved video and audio calls

## SiskinIM 5.5

The stable release of SiskinIM 5.5 contains the following changes:

- Added support for encrypted file transfer (AESGCM)
- Improved file and photo transfer
- Changed UI of chats
- Added support for blocking contacts
- Improved push notifications support
- Added link previews

![siskin-file-preview]({{ site.url }}{{ site.baseurl }}/assets/posts/siskin-file-preview.png)


You can download both application from their respective app-stores: [Beagle IM](https://beagle.im/) from [macOS appstore](https://apps.apple.com/us/app/beagleim-by-tigase-inc/id1445349494) and [Siskin IM](https://siskin.im/) from [iOS appstore](https://itunes.apple.com/us/app/tigase-messenger/id1153516838) and star them on GitHub: [Siskin IM on GitHub](https://github.com/tigase/siskin-im) and [Beagle IM on GitHub](https://github.com/tigase/beagle-im)
